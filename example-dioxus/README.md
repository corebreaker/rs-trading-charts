# Example for Trading Charts Dioxus

## Pre-requisites
### Trunk
```bash
cargo install trunk
```

## Run
```bash
trunk serve
```

## This example
This example demonstrates how to use the `trading-charts-dioxus` crate.
It is a Rust binding of [Lightweight Charts] for [Dioxus].

You can find the source code in the `src` directory.
